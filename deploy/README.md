# Стенд

Стенд для теста с детьми и защиты: PostgreSQL, API (2 процесса uvicorn)
и Nginx, который отдаёт собранный фронтенд и проксирует `/api`.
Работает по HTTPS: телефон открывает его по адресу ноутбука в локальной сети.

## Первый запуск

```bash
cp .env.prod.example .env.prod   # и заменить все change-me
./deploy/up.sh
```

`up.sh` выпускает самоподписанный сертификат на IP ноутбука (если его ещё нет),
собирает образы, поднимает стенд, применяет миграции и создаёт демо-семью.
В конце печатает адрес вида `https://192.168.1.10`.

Если интернет на машине идёт через прокси, сборке его нужно передать:

```bash
BUILD_PROXY=http://host.docker.internal:7890 ./deploy/up.sh
```

## С телефона

Телефон и ноутбук — в одной сети Wi-Fi. Открыть адрес из вывода `up.sh`.
Сертификат самоподписанный, поэтому при первом открытии браузер покажет
предупреждение: его нужно принять один раз. Вход — почта и пароль
демо-взрослого из `.env.prod`, PIN детского режима — 2580.

## Перед каждым ребёнком

```bash
./deploy/reset-demo.sh
```

Сначала журналы всех детских сессий демо-семьи сохраняются в `exports/`
(CSV, время в секундах от начала сессии), затем семья создаётся заново.
Структура базы не меняется.

## На VPS

То же самое, но сертификат — от Let's Encrypt для домена:
положить `fullchain.pem` и `privkey.pem` как `deploy/certs/stand.crt`
и `deploy/certs/stand.key` и запустить `./deploy/up.sh`.
Открыты должны быть порты 80 и 443.

## Проверка

```bash
curl -k https://<адрес>/api/health   # {"status":"ok"}
```
